AutomationKit 目录页设计文档

site/templates.html · 给潜在客户看的模板目录页
版本 0.1.0 ｜ 2026-11-01 ｜ 单文件静态页，无构建、无外部依赖

页面定位

这不是营销落地页，是产品目录。客户打开后要在 30 秒内回答三个问题：

#客户心里的话页面哪一部分回答
1有哪些现成模板？顶部总览表，6 行一屏看完
2我要的那类工作流在不在里面？模板卡片的一句话作用描述
3装起来麻烦吗？要花多少钱？总览表「需要付费账号」列 + 三步导入章节

刻意不做的事：不放客户 logo 墙、不放 testimonials（还没有）、不放价格表（价格在 Upwork 服务包里，不在这页）。这一档（$95–$380）的客户看的是「能不能用」，不是品牌故事。

信息架构

顺序区块作用
1文档头标题 + 一行副标题（6 个模板 / 含重试与错误处理）+ 版本与运行时信息
2模板总览6 行表格：模板 / 触发 / 依赖服务 / 是否要付费账号 / 是否含错误分支
3Webhook 类（3 个）lead-routing、support-triage、invoice-parsing
4定时类（3 个）rss-summary、sheets-notion-sync、daily-digest
5三步导入起环境 / 导入 JSON / 填凭证并激活
6三条工程契约重试 / 错误分支 / 幂等——这是差异化卖点，放最后收尾

分组依据是触发方式而不是业务领域。客户找模板时先想到「我是定时跑还是被事件触发」，这与他们的心智模型一致。

模板卡片字段规范

6 张卡片字段顺序完全一致，方便客户横向比对。每张卡必须能回答：它干什么、怎么触发、要什么凭证、失败了会怎样。

序字段写法要求
1标题（h3）「模板名 · 中文名」格式，如 lead-routing · 客户线索分发
2一句话作用主谓宾齐全，不用形容词。如「表单来一条线索，去重后写进 CRM，同时通知销售群」
3副行（tagline）三个卖点用 · 分隔，如「Webhook 触发 · 失败自动重试 3 次 · 同一条线索永不被处理两次」
4触发给出确切的 URL 与 body 字段名
5需要的凭证逐项列清；自带的说「自带」
6失败时会发生什么必须写具体行为，不能写「会自动重试」了事。要写清：重试几次、失败后进哪张表、有没有数据丢失
7判断/去重规则去重粒度、置信度阈值、单向还是双向——这是客户最可能追问的点

第 6 项是本页的核心竞争力。市面上模板包几乎都不写「失败时会发生什么」，而客户真正被坑过的正是这一点。这一栏写得越具体，报价越站得住。

交互规范

交互行为
右侧目录点击平滑滚动到对应锚点；scroll-margin-top: 20px 防止标题被顶部裁掉
滚动高亮随滚动更新当前章节（判定线为视口顶部 +120px）
目录悬停文字由次要色变标题色，无位移、无动画
窄屏≤1419px 隐藏右侧目录，内容单栏
外部链接本页暂无外链；若后续添加 n8n 文档链接，需 target="_blank" rel="noopener" 并加 ↗ 标记

不用悬浮动画与渐变：这是 B2B 工具目录页，客户的注意力应该全部落在「失败时会怎样」这些文字上，而不是界面特效上。

打印规范

  • A4 竖版，页边距 14mm × 15mm
  • 整体反色：白底黑字，color-scheme: light + print-color-adjust: exact
  • 右侧目录自动隐藏，内容区取消右内边距
  • 表格、卡片、代码块禁止跨页断行（page-break-inside: avoid）
  • 打印后可直接作为报价附件发给客户
